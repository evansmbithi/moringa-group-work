# Paypal-to-Mpesa
A secure and seamless way to withdraw funds from PayPal directly to MPesa via the MPesa Super App.

## Setup Instructions
1. Clone the repository to your local machine.
2. Navigate to the project directory.
3. Run `npm install` to install dependencies.
4. Run `npm start` to start the development server.

## Behavior-Driven Development (BDD)
Features
- Secure PayPal Account Linking – Users can connect their PayPal accounts via OAuth.
- Check PayPal Balance – Display available funds for withdrawal.
- Instant MPesa Withdrawals – Transfer funds to MPesa in real-time or within a short processing period.
- Transaction History – Keeps records of all past transactions.
- Two-Factor Authentication (2FA) – Secure withdrawals via OTP or MPesa PIN.
- Customer Support & FAQs – Assistance for linking and transaction issues.
